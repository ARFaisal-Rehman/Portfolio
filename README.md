# Abdul Rehman Faisal: Windows XP Portfolio

A playful Windows XP-style desktop portfolio: boot screen, login, draggable windows, Minesweeper and Snake. Live at **https://arfaisal-rehman.github.io/Portfolio/**

Single self-contained `index.html` (HTML, CSS and vanilla JS) using [XP.css](https://botoxparty.github.io/XP.css/). Deployed with GitHub Pages from `main`. Not affiliated with Microsoft.

The main, mobile-first portfolio is **Field Notes**: https://arfaisal-rehman.github.io/new-portfolio/
